# 趁热打铁
1.你在这个任务之中，选择了什么激活函数，为什么选这个？  
- 隐藏层使用 ReLU，输出层使用 Sigmoid。
- ReLU：引入非线性，没有激活函数网络只能拟合直线；ReLU计算简单，缓解梯度消失，适合浅层MLP。
- Sigmoid：把输出压缩到 (0,1)，输出二分类的概率值，配合BCELoss使用。  

2.你选择了什么损失函数？为什么？那如果这一题是三分类问题呢？  
- 二分类任务使用 BCELoss（二元交叉熵）。  
- BCELoss专门用来处理二分类概率输出，与适用场景匹配。
用来衡量预测概率和真实标签之间差距。
- 三分类任务，用CrossEntropyLoss。
网络输出层不使用Sigmoid，直接输出3个类别的原始得分logits。CrossEntropyLoss内部会自动做Softmax，把3个输出转为各类概率，计算多分类交叉熵。


3.optimizer.zero_grad()、loss.backward() 和 optimizer.step() 分别完成了什么工作？如果不清空梯度会发生什么？  
- optimizer.zero_grad()：清空上一轮保存的梯度。
- loss.backward()：反向传播，自动求导，计算损失对网络权重的梯度，存到参数.grad。
- optimizer.step()：优化器根据梯度更新模型权重。
- 不清空梯度：梯度会累加，参数更新方向错乱，训练不收敛。

4.更深、更宽的神经网络一定能取得更好的效果吗？模型过于简单或过于复杂分别可能带来什么问题？  
- 不一定。
- 模型太简单（容量不足）：欠拟合，训练集loss降不下去，训练、验证效果都差。
- 模型太复杂：容量过大，容易过拟合：训练集loss很低，验证集loss明显更高，泛化能力变差。

5.学习率过大或过小会怎样影响模型训练？你能从 loss 曲线中观察到哪些现象？  
- 学习率过大：参数更新步子太大，会在损失函数最低点来回跳跃震荡；loss曲线上下剧烈波动，无法平稳下降，严重时损失直接爆炸，模型不收敛。
- 学习率过小：参数每次改动幅度很小，loss下降非常缓慢；loss曲线是一条平缓下降的斜线，需要非常多轮epoch才能收敛，训练耗时很长。
- 本次实验曲线观察：我们设置学习率lr=0.01，loss曲线平滑下降，训练loss与验证loss同步降低，后期趋于平稳，没有震荡，模型稳定收敛，说明当前学习率选择合适。

6.假设还有一个分类问题，但是两个类别的样本数量非常不均衡，训练出来的模型会怎么样？为什么？说明了什么？  
- 模型现象：模型会偏向样本数量多的大类。整体准确率看起来很高，但对少数类的识别效果很差。
- 原因：损失函数会被数量更多的样本主导。模型只要把大多数样本预测成占比高的类别，就能拿到很低的loss，不会花精力去学习少数类样本的特征。
- 说明：单纯的准确率在样本不均衡任务里是不可靠的评价指标，不能只用准确率衡量模型好坏；需要采用加权损失、重采样等方式解决类别不平衡。

7.如果想要过拟合这个数据集，你会怎么做？为什么？试试看能不能实现吧！（在别的数据集也可以）训练过程和数据呈现和正常训练有何不同？你通过什么判断他过拟合？  
- 怎么做：  
1.增大模型容量：增加隐藏层数量 / 大幅度增加隐藏层神经元个数。  
2.减少训练数据，或者去掉正则化（不使用dropout、不做权重衰减）。  
3.增大训练轮数，让模型充分长时间训练。
- 原理：    
更大容量的模型拥有极强拟合能力，不仅学到数据本身的分类规律，还会记住训练集里的噪声和随机样本细节。
- 训练现象：  
1.训练loss持续下降，训练集准确率几乎接近100%；  
2.验证集loss先降后上升，验证集准确率在后期开始下降。  
3.正常拟合：训练loss、验证loss同步下降，两者差距不大。
- 判断过拟合的依据：  
观察loss与acc曲线：训练集效果持续变好，但验证集效果变差，训练集和验证集指标差距明显拉大，就是过拟合。
# 任务四观察结果  
### 实验一：改变隐藏层神经元数量
- 4神经元：参数量最少，显存占用最低、训练最快；模型容量不足，欠拟合，验证准确率0.86，loss无法降到很低。
- 16神经元（基线）：显存、训练速度适中，容量适配月牙任务，验证准确率0.97，训练与验证指标差距小，泛化性能好。
- 128神经元：参数更多，显存占用更大、训练耗时更长；拟合能力更强，验证准确率小幅提升至0.985，但收益有限。
### 实验二：改变学习率（固定网络16神经元）
- lr=0.001：参数更新步长很小，收敛很慢，1000轮epoch还未充分收敛，最终验证准确率0.87。显存占用不变，只是训练需要更多迭代次数。
- lr=0.01（基线）：步长合适，收敛速度适中，稳定达到0.97验证准确率。
- lr=0.1：更新步长偏大，收敛速度最快，最终验证准确率0.98；loss曲线存在小幅震荡，学习率过大容易跳过最优解，在复杂任务会出现明显震荡、不收敛。
### 总体结论
- 隐藏层神经元数量决定模型容量：神经元越多拟合能力越强，但算力开销更大；简单任务下盲目增大网络，精度提升很小，复杂任务更容易出现过拟合。
- 学习率控制参数更新步长：学习率太小收敛极慢；学习率太大容易震荡、无法找到最优参数，需要选取合适的学习率。
