# 实践1
1.了解数字图片如何被表示，并回答：像素是什么？什么是 RGB？灰度图和彩色图有什么区别？  
- 像素：构成数字图像最小单元，一张图片由大量像素点平铺组成；每个像素存储亮度/颜色数值。
- RGB：彩色图像常用的色彩表示方法，R(红)、G(绿)、B(蓝)三个颜色通道。每个通道用0~255整数表示亮度，三个通道混合，就能合成各种各样颜色。
- 灰度图 vs 彩色图  
灰度图：只有1个通道，只记录亮度，0纯黑，255纯白，没有色彩信息。shape一般 [H, W] (高、宽)。  
彩色RGB图：3个通道R/G/B，每个像素同时存3个亮度值，包含颜色信息。shape一般 [H, W, 3]。

- HWC 和 CHW 的区别

CHW（PyTorch张量）：[C, H, W]。通道放在最前面，是卷积运算的标准格式，便于GPU并行计算每个通道。

3.了解二维卷积的基本过程。用自己的话解释：卷积核是什么？它在图片上怎样移动？每到一个位置进行了什么计算？  
- 卷积核是小型权重矩阵，用于提取图像特征。它按固定步长在图像上从左到右、从上向下滑动；在每个位置，卷积核与覆盖区域像素逐元素相乘后求和，得到输出像素。

锐化：例如使用 [[0,-1,0],[-1,5,-1],[0,-1,0]]；

6.观察并解释每种处理带来的变化：为什么均值与高斯卷积会让图片变模糊？为什么锐化会让边缘更明显？Sobel 卷积核为什么能找到边缘？  
- 均值模糊：将窗口内像素求平均，抹平像素突变，图像变平滑模糊。
- 高斯模糊：邻域加权平均，中心权重更高，实现更自然的模糊。
- 锐化：放大中心像素，减去周围像素，增强边缘区域的明暗对比度，轮廓更明显。
- Sobel：计算像素亮度梯度，像素明暗剧烈变化处输出高值，以此提取图像边缘；Sobel-X捕捉竖直边缘，Sobel-Y捕捉水平边缘，合并得到完整边缘图。

7.分别尝试不填充（valid）和适当填充（same）图片边缘，比较输出尺寸与边缘像素的变化。记录卷积核大小、padding、stride 与输出尺寸之间的关系。  
- 对比结果：  
Valid(padding=0)输出尺寸538×958，相比原图缩小，边缘像素丢失；  
Same(padding=1)输出尺寸540×960，与原图尺寸一致，通过外围补0保留全部原图像素参与卷积，但边缘引入了补0带来的计算偏差。  
- 卷积输出尺寸公式：  
H_out = floor((H_in + 2*padding - kernel_size)/stride) + 1  
W_out = floor((W_in + 2*padding - kernel_size)/stride) + 1  
- Valid（padding=0）：无填充，输出图尺寸缩小，原图边缘信息丢失。
- Same（补0填充）：四周补0，输出尺寸与输入一致，保留边缘像素。
- 规律：卷积核越大、stride越大，输出尺寸越小；padding越大，输出尺寸越大。

# 趁热打铁
1. 卷积层为什么比巨大全连接层更适合处理图片？试着用全连接层实现本任务，对比差距  
- 核心三点：参数更少、保留空间位置信息、具备平移不变性
- 巨大全连接层会把图像像素全部展平，丢失像素之间空间、邻域位置关系，无法利用图片局部纹理、边缘信息；参数量爆炸，极易过拟合。
- 卷积利用权值共享+局部感受野，同一个卷积核在整张图像滑动，参数量大幅降低，不容易过拟合；可以提取边缘、纹理这类局部空间特征，图像发生小幅平移依然可以识别。
- 对比差距：纯全连接模型收敛慢、验证精度低、过拟合严重；CNN收敛更快，泛化能力更好。
2. 卷积层的输入通道和输出通道分别表示什么？它们与卷积核的数量有什么关系？
- 输入通道：输入特征图的深度。RGB图像输入通道=3，灰度图=1；上一层输出多少通道，这一层输入通道就是多少。
- 输出通道：该卷积层一共提取多少种不同类型的特征。
- 关系：输出通道数 = 卷积核的数量；每一个卷积核的通道维度必须和输入通道保持一致。
- 举例：输入通道3，输出通道32 → 一共有32个3通道的卷积核。
3. padding、stride 和 pooling 会怎样改变特征图的尺寸？结合自己网络中的一层实际计算
- 尺寸计算公式：
- H_{out}=\frac{H_{in}+2\times padding - kernel\_size}{stride}+1
- stride：步长越大，输出特征图宽高越小
- padding：补零，padding越大，输出宽高越大，valid模式padding=0，same保证输入输出尺寸不变
- pooling：池化一般stride和池化核大小相等，用来压缩宽高，降低分辨率
- 结合网络第一层卷积计算：  
输入 H_{in}=150，kernel=3，stride=1，padding=valid（0）
H_{out} = \frac{150 + 0 - 3}{1}+1 = 148
输出尺寸 (148,148,32)，和你结构图完全一致。
4. 随着网络逐层计算，特征图的宽和高通常越来越小，通道数却可能越来越多，这是为什么？
- 宽高变小：卷积+池化不断压缩空间维度，舍弃不重要的细节信息，降低计算量，让感受野变大，能够捕捉更大范围语义特征。
- 通道变多：空间分辨率下降之后，每一个像素点对应的语义信息更复杂，需要更多通道用来编码多种不同的高层语义特征（轮廓→部件→物体）。
5. 你选择了什么激活函数和损失函数？它们为什么适合这道二分类题？
- 激活函数：卷积层使用 ReLU，输出层使用 Sigmoid
- ReLU：计算快，缓解梯度消失，适合中间隐藏层特征提取；
- Sigmoid：输出范围 [0,1]，可以直接解释为属于猫/狗的概率。
- 损失函数：二元交叉熵 BinaryCrossentropy，专门用于二分类概率预测，衡量预测概率与真实标签之间分布差异。
6. 为什么训练集上的随机数据增强不直接用在验证集和测试集？翻转、裁剪和颜色变化分别可能带来什么帮助或问题？
- 原因：验证、测试集用来评估模型在真实原始图像上的性能，不能引入随机扰动；如果验证测试也做增强，评估结果会存在随机性，无法客观反映模型泛化能力。
- 翻转：有效，猫狗大多左右对称，提升样本多样性；一般不做上下翻转。
- 随机裁剪：模拟物体位置偏移，增加位置鲁棒性；裁剪幅度过大有可能丢失主体目标，引入无效样本。
- 颜色扰动：提升光照、色彩变化鲁棒性；扰动幅度太大，图像失真，标签和图像语义不匹配。
