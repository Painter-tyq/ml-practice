### 三、 核心知识点总结
1. **Scaled Dot-Product Attention**：把输入看作 Q、K、V。通过 Q 和 K 的点积算相似度，除以 $√d_k$ 缩放后，用 Softmax 转为概率权重，最后对 V 加权求和。
2. **Multi-Head Attention**：把 Q、K、V 映射到多个子空间（多头），并行做 Attention，最后拼接。目的是让模型在不同的子空间关注不同的信息（如语法、语义）。
3. **Position-wise FFN**：两层线性层 + ReLU。对序列中每个位置独立进行非线性变换（参数共享）。
4. **Positional Encoding**：由于 Self-Attention 没有顺序感知，使用 sin/cos 固定公式将位置信息相加到输入嵌入中。

### 四、 遇到的难点与突破（灵魂部分）

#### 难点 1：Q、K、V 到底是怎么来的？
- **初读感受**：一开始以为 Q、K、V 是三个不同的输入，觉得矩阵相乘很混乱。
- **如何理解**：想象成“图书检索系统”。Query 是搜索词，Key 是图书的标签，Value 是图书的内容。在当前的自注意力层中，Q、K、V 其实都是同一个输入矩阵 X 乘以不同的可学习权重矩阵（$W_Q, W_K, W_V$）得到的。
- **最终结论**：Q、K、V 是输入 X 在不同空间的投影。（详细见第六题）

#### 难点 2：为什么要除以 $√d_k$?（缩放）
- **初读感受**：只看到了公式，不理解“缩放”的物理意义，不知道不除会怎样。
- **如何理解**：假设 $d_k$ 很大，点积的结果会变得非常大。如果不缩放直接放进 Softmax，会导致 Softmax 的梯度变得极小（梯度消失），模型无法学习。除以 $√d_k$ 可以让方差保持在 1 左右，保证训练稳定。
- **最终结论**：这是防止梯度消失的工程技巧。

#### 难点 3：Positional Encoding 为什么用 sin/cos？
- **初读感受**：公式复杂，觉得完全可以像 RNN 一样用可学习的位置嵌入。
- **如何理解**：正弦余弦公式具有三角恒等式特性，能让模型轻松学习到**相对位置**（PE(pos+k) 可以表示为 PE(pos) 的线性函数），并且具有很好的外推性（测试集比训练集长也能算）。
- **最终结论**：固定公式可以避免引入额外参数，且具备外推性。

#### 难点 4：在 Cursor 里 Markdown 公式渲染失败
- **初读感受**：复制了带 `$` 和 `\frac` 的文本，预览里变成了一堆乱码 `((QK^T))` 和 `(\frac{...})`。
- **如何理解**：Cursor（VS Code）默认不支持 LaTeX 渲染。解决方案是安装 `Markdown All in One` 插件，并在预览时使用 `Ctrl+Shift+V`。
- **最终结论**：工欲善其事，必先利其器。装好插件后公式完美显示。
